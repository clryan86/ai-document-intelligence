# Recruiter Overview

## Project
**Document Intelligence Workbench**

## One-line description
A deployable Python/FastAPI application that converts unstructured documents into a searchable, summarized knowledge base using local NLP.

## Skills demonstrated

- Python backend development
- FastAPI / REST API design
- SQLAlchemy / relational data modeling
- PDF and text processing
- applied NLP / information retrieval
- automated testing
- GitHub Actions CI
- Docker
- software architecture documentation
- secure file-handling fundamentals

## Why it is more than a tutorial

The project has an end-to-end business workflow, persistence, duplicate detection, failure handling, typed API responses, automated integration tests, a browser interface, Docker packaging, CI, architecture documentation, API documentation, and an explicit production-hardening roadmap.
